# CBSA Indicator and Critical-Data-Element Cross-Journey Usage Matrix

## Legend

| Cell Value | Meaning |
|---|---|
| `C` | create - the feature or endpoint brings the indicator or CDE into existence; joins to Operation `create` in inventory.md |
| `W` | write - the feature or endpoint assigns or updates the stored value; joins to Operation `write` in inventory.md |
| `R` | read - the feature or endpoint reads the stored value without modifying it; joins to Operation `read` in inventory.md |
| `X` | consume - the feature or endpoint receives the value across a tier boundary and acts on it; joins to Operation `consume` in inventory.md |
| (empty) | not used - the feature or endpoint has no create, write, read or consume relationship with the indicator or CDE |
| (precedence) | where several operations apply to one cell, the cell carries the highest by `C` > `W` > `R` > `X`; DBCRFUN both reads and writes `account-available-balance` within F-015, so that cell carries `W` |
| (endpoint columns) | an endpoint column carries a token when the indicator is a declared property of that endpoint's request or response contract in its Swagger definition, or a field the JAX-RS handler places in its JSON response, or a value the handler originates or mutates; a field only hydrated into a transient object and never exposed or mutated carries no token |
| (empty column) | four endpoint columns carry no token at all, which is a positive determination rather than an omission: GET /webui-1.0/banking/customer/all/town/{town}, GET /webui-1.0/banking/customer/all/surname/{surname} and GET /webui-1.0/banking/customer/all/age/{age} return only customer number, name, address and date of birth, and PUT /webui-1.0/banking/customer/{id} writes only name and address, so none of them touches any indicator or CDE in this registry |
| (projected column) | an endpoint column carries `R` where that endpoint's accessor query projects the DB2 column physically carrying the indicator without binding it into the response DTO, so the read occurs at the SQL projection level; this is why GET /webui-1.0/banking/processedTransaction carries `R` for proctran-eye-catcher and for proctran-logical-delete-flag, whose byte the eye-catcher column holds |
| (generated accessor with no caller) | a feature column carries `W` or `R` where the only in-repository write or read path is a generated commarea accessor that has no in-repository caller, which is why F-007 carries `R` for newaccno-function-flag and F-006 carries `R` for newcusno-function-flag; the missing caller is recorded as a determination in the corresponding inventory row rather than as an empty cell |
| (csv twin) | `docs/indicators/usage-matrix.csv` carries no legend row, because a legend row would corrupt its machine-queryability; this section is the legend for both files |
