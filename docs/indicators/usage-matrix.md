# CBSA Indicator and Critical-Data-Element Cross-Journey Usage Matrix

## Legend

| Cell Value | Meaning |
|---|---|
| `C` | create - the feature or endpoint brings the indicator or CDE into existence; joins to Operation `create` in inventory.md |
| `W` | write - the feature or endpoint assigns or updates the stored value; joins to Operation `write` in inventory.md |
| `R` | read - the feature or endpoint reads the stored value without modifying it; joins to Operation `read` in inventory.md |
| `X` | consume - the feature or endpoint receives the value across a tier boundary and acts on it; joins to Operation `consume` in inventory.md |
| (empty) | not used - the feature or endpoint has no create, write, read or consume relationship with the indicator or CDE |
| (precedence) | where several operations apply to one cell, the cell carries the highest by `C` > `W` > `R` > `X`, and the per-operation evidence a collapsed cell draws on is the set of rows for that indicator in `docs/indicators/inventory.md` |
| (endpoint columns) | an endpoint column carries a token when any artifact in that endpoint's complete request-handling chain creates, writes, reads or consumes the indicator, the chain running from the REST or JAX-RS handler through the controller, the JSON DTO, the generated commarea class and the DB2 or VSAM accessor to the backend program the endpoint reaches; the chain is not narrowed to the fields declared on the wire contract, and the binding that resolves each endpoint to its backend program is cited row by row in `docs/indicators/inventory.md` |
| (chain evidence) | every nonempty endpoint cell is backed by at least one physical row in `docs/indicators/inventory.md` whose Program/API/Job cell names that exact endpoint and whose Operation cell carries the operation the token collapses from, so the matrix and the inventory are joinable in both directions |
| (physical read) | a read counts when the indicator's physical DB2 column or VSAM record field is projected by the statement or hydrated from the record buffer, even where the value is never bound into the response DTO; the projecting statement or hydration site behind each such cell is cited row by row in `docs/indicators/inventory.md` |
| (empty endpoint cell) | an empty endpoint cell means no artifact anywhere in that endpoint's complete chain touches the indicator; every one of the 38 endpoint columns in the matrix below carries at least one token, so no endpoint column is empty |
| (no unsupported cell) | a cell is carried only where a real in-repository call path exists; where a generated commarea accessor has no in-repository caller no cell is carried, and that no-caller determination is recorded as a row in `docs/indicators/inventory.md` instead |
| (csv twin) | `docs/indicators/usage-matrix.csv` carries no legend row, because a legend row would corrupt its machine-queryability; this section is the legend for both files |
